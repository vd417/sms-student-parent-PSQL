# Road-Following Route Geometry (sms-student / Parent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the straight-line route polyline in the parent-facing `BusMap` (native `react-native-maps` + web `Leaflet`-in-`WebView`) with road-following geometry, without touching child authorization, live tracking, or ETA.

**Architecture:** A new HTTP repo function + shared polyline decoder + React Query hook feed a decoded road path into both `BusMap.native.tsx` and the Leaflet HTML generated by `busMapHtml.ts`, replacing the current straight `L.polyline`/`Polyline` construction. Falls back to an explicit "Route unavailable" state, never the old straight line.

**Tech Stack:** React Native/Expo, `react-native-maps` (native), Leaflet-in-`WebView` (web fallback), TanStack React Query, `@microsoft/signalr` (untouched by this plan).

**Spec:** `docs/superpowers/specs/2026-09-19-road-following-route-geometry-design.md`

## Global Constraints

- Depends on the finalized `sms-backend` contract: `GET /v1/transport/routes/{routeId}/geometry`.
- Never fall back to the existing straight-line construction as production behavior when geometry is `unavailable` — show "Route unavailable" instead.
- Do not touch `useTransportFleetPush`, `JoinMyChildrenBuses`/`JoinBus` fallback, `applyBusPositionPush`/`parseBusPositionPush`, multi-child switching, or ETA.
- Do not call the geometry endpoint per GPS/lifecycle SignalR event — fetch once per selected child's `routeId` via React Query.

/** Decodes Google's polyline algorithm format into RN-Maps-shaped coordinates. */
export function decodePolyline(encoded: string): { latitude: number; longitude: number }[] {
  if (!encoded) return []
  const points: { latitude: number; longitude: number }[] = []
  let index = 0
  let lat = 0
  let lng = 0

  while (index < encoded.length) {
    lat += decodeSignedValue()
    lng += decodeSignedValue()
    points.push({ latitude: lat / 1e5, longitude: lng / 1e5 })
  }
  return points

  function decodeSignedValue(): number {
    let result = 0
    let shift = 0
    let byte: number
    do {
      byte = encoded.charCodeAt(index++) - 63
      result |= (byte & 0x1f) << shift
      shift += 5
    } while (byte >= 0x20)
    return (result & 1) !== 0 ? ~(result >> 1) : result >> 1
  }
}
```

export interface RouteGeometryDTO {
  routeId: string
  status: 'available' | 'unavailable'
  format: string | null
  geometry: string | null
  distanceMeters: number | null
  durationSeconds: number | null
  stopSequenceHash: string
  generatedAt: string | null
}

// Adapt to this app's actual HTTP client call signature (confirmed in Step 1) —
// this is the shape, not a literal copy-paste:
export async function getRouteGeometry(http: HttpClient, routeId: string): Promise<RouteGeometryDTO> {
  const res = await http.get(`/transport/routes/${routeId}/geometry`)
  return {
    routeId: res.data.route_id,
    status: res.data.status,
    format: res.data.format,
    geometry: res.data.geometry,
    distanceMeters: res.data.distance_meters,
    durationSeconds: res.data.duration_seconds,
    stopSequenceHash: res.data.stop_sequence_hash,
    generatedAt: res.data.generated_at,
  }
}
```

    queryFn: () => getRouteGeometry(http, routeId as string),
    enabled: !!routeId,
    staleTime: 60_000,
  })
}
